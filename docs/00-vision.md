# 00 · 目标愿景

## 我们要造什么

一个语言系统内核：输入用户一句话，输出「台词 + 旁白」两轨内容，并且跨会话记得住这个用户。

它管角色是谁、记得什么、该怎么说，不管把声音合成出来、也不管让脸动起来。

位置关系：

```
用户说话
  ↓
Language Core（本项目）→ 台词 + 旁白
  ↓
FLP 视频链路（TTS + Agora RTC + AVTR 形象驱动）
  ↓
用户听到声音、看到表情
```

## 为什么先做它

现有三块资产各自缺一块：

- FLP 有传输、形象驱动、语音，没有记忆和角色系统
- companion-prototype 有完整界面，没有真实 AI 和记忆
- 聊天提示词目录是网上找的参考，与本产品无关

缺的正好是"脑"。而且它必须先行：视频链路依赖它的输出格式，且它能脱离视频独立验收。

### 成功标准的校准状态

00 文档里的及格线（格式稳定率 ≥95%、跨会话承接率 ≥60%、错误记忆率 ≤3%、跨场景人格一致率 ≥85%）是**目标值，不是实测值**。目前只有格式稳定率可以从真实模型跑出来，
其余几项需要先建对应的测试集才能测，还要用真实模型输出校准基线。

## 不做什么

TTS 合成、形象驱动、实时传输、商业化界面、多角色互通、用户自建角色、未成年人模式。前四项由现有资产或下游负责，后三项明确推迟。

## 设计原则

1. 台词与旁白严格分离，旁白绝不朗读
2. 角色卡与场景卡正交，N 角色 + M 场景 = N+M 份内容而非 N×M
3. 记忆只有一个分区维度：角色。场景是标签不是隔离墙
4. 未解锁信息物理上不进上下文，不是"告诉模型别说"
5. 模型输出必须可校验，稳定性不能只押在提示词上
6. 记忆写入异步，不阻塞回复
7. 关系状态是角色级，换场景不改"我们多熟"
8. 一切可回滚

## 成功标准

功能验收：

- 关掉页面再打开，她记得上次说过的事
- 换场景后仍是同一个人，且不退回生疏
- 输出 100% 可解析为双轨结构
- 用户删除的记忆不再出现
- 未解锁的深层信息不会被提前说出
- 改角色卡不需要动场景卡
- 换 LLM 引擎业务逻辑零改动

质量指标及格线：格式稳定率 ≥95%，跨会话承接率 ≥60%，错误记忆率 ≤3%，跨场景人格一致率 ≥85%，记忆删除完整率 100%，未解锁信息泄露率 0%。

不能用来衡量成功的：对话轮次多、回复长度、信息密度。陪伴产品允许沉默和废话。

## 主要风险

人格漂移、错误记忆沉淀、复读机、场景穿帮、深层信息泄露、过度迎合、召回失败静默（不报错，只表现为"她失忆了"）。
